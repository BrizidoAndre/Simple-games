# Simple Games Collection

## 🕹️ Coleção de Jogos Simples em HTML, CSS e JavaScript

O repositório **Simple Games Collection** é uma pequena coleção de jogos clássicos e simples desenvolvidos com as tecnologias fundamentais do *frontend*: **HTML**, **CSS** e **JavaScript**. O projeto serve como um portfólio prático para demonstrar a implementação da lógica de jogos e manipulação do DOM (Document Object Model) usando JavaScript puro.

### ✨ Jogos Incluídos

O repositório é organizado em pastas, onde cada pasta contém um jogo completo:

| Pasta | Jogo | Descrição Breve |
| :--- | :--- | :--- |
| **memory-game** | Jogo da Memória | Implementação clássica do jogo da memória. |
| **pong** | Pong | Versão simples do clássico jogo de arcade Pong. |
| **snake** | Snake | Versão simples do clássico jogo da cobrinha. |
| **tic-tac-toe** | Jogo da Velha (Versão 1) | Implementação básica do Jogo da Velha. |
| **tic-tac-toe-2** | Jogo da Velha (Versão 2) | Uma segunda implementação do Jogo da Velha, possivelmente com melhorias ou abordagem diferente. |

### 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso Principal |
| :--- | :--- |
| **HTML5** | Estrutura e marcação de todos os jogos. |
| **CSS3** | Estilização e design dos jogos. |
| **JavaScript** | Lógica de jogo, manipulação do DOM, controle de estado e interatividade. |

### 📂 Estrutura do Projeto

O repositório é estruturado para fácil acesso a cada jogo:

```
Simple-games/
├── .idea/          # Arquivos de configuração do ambiente de desenvolvimento
├── memory-game/    # Jogo da Memória
├── pong/           # Jogo Pong
├── snake/          # Jogo Snake
├── tic-tac-toe/    # Jogo da Velha (Versão 1)
├── tic-tac-toe-2/  # Jogo da Velha (Versão 2)
└── README.md       # Este arquivo
```

### 🚀 Como Jogar

Para jogar qualquer um dos jogos, basta clonar o repositório e abrir o arquivo `index.html` dentro da pasta do jogo desejado em seu navegador web.

**Exemplo para o Jogo Pong:**

```bash
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/Simple-games.git

# 2. Navegue até o diretório do jogo
cd Simple-games/pong

# 3. Abra o arquivo index.html no seu navegador
# (Exemplo para Linux/macOS)
open index.html
# (Exemplo para Windows)
start index.html
```
